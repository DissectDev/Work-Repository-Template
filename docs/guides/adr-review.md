# ADR 七问评审

本页是对 Olaf Zimmermann 七问清单的中文概括，用于起草或评审时参考；它不是 MADR 模板的必填部分，也不自动引入审批要求。

* [ ] 问题的重要程度值得单独决策和记录。
* [ ] 候选方案能够回应问题，未遗漏明显可行的替代方案。
* [ ] 判断标准尽量减少重复，并覆盖关键关注点。
* [ ] 标准冲突时，优先级已经说明。
* [ ] 选择与原问题相符，理由能够支撑结论。
* [ ] 各方案的收益与代价得到客观说明。
* [ ] 决策可执行、可追溯到需求，并说明复查日期或有效期。

需要记录评审结果时，注明目标 ADR 及其版本，将具体发现写在关联 PR 或评审记录中。本页保留为通用检查清单。不适用的项目可以注明原因。

依据不足时，写清需要补充什么证据，不必把每次评审变成完整研究。
