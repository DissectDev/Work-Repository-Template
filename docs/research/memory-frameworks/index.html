DolphinBench

DolphinBench grades whether an agent completes real tool-using tasks that depend on facts from about 500K tokens of a simulated user's history, across 600 tests for three personas (Morgan, Alex, Riley). It reports accuracy, total cost and latency together, so the useful view is the cost-versus-accuracy frontier.

Method notes

  • DolphinBench is published by Mem0, one of the frameworks compared here. The run records are public and include every trace and grade, but the benchmark design is vendor-authored.
  • In the official runs, Mem0 used the harness's memory plugin with the hosted Mem0 Platform; Hindsight ran self-hosted from its 0.9.2 Docker image. Cognee, Zep and GraphRAG have no official run.
  • Total cost covers agent model calls and memory-system processing during ingestion and testing. Cost per pass is total cost divided by passed tests. Lift is the pass-rate difference from the same harness and model with built-in memory.
  • API fit is the sum of four 0 to 3 ratings, one per verb. Setup effort is a 1 to 5 rating. Both are judgments from the documented APIs and install paths on 12 Oct 2026, not measurements.
  • Backend counts include community adapters and wrappers that ship or are documented by the project; Zep's count is for its open-source Graphiti engine, since Zep Cloud runs its own graph engine.
